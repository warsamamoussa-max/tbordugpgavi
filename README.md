## Développement local
```bash
npm install && npm run dev
```

## Déploiement GitHub → Netlify
1. Push ce dépôt sur GitHub
2. Netlify → Add new site → Import from Git → sélectionner le repo
3. `netlify.toml` configure tout automatiquement
4. Site settings → Storage → Enable Netlify Blobs
